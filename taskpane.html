There's one copy of each diagram, in your Lucid account. This editor and lucid.app are two windows onto that same diagram: edit in either, and every change saves to Lucid by itself.

The pictures in the document are snapshots. Insert adds the diagram as a new picture below the cursor; Update brings the selected picture up to date. The line above the buttons says whether it is. Edit selected opens the selected picture's diagram here.

The menu at the top switches diagrams: the ones already in this document, your recent ones, or Browse or create in Lucid. ↗ opens the diagram on lucid.app for more room and the Lucid features that don't work in the add-in, like Create with AI; ↻ reloads the editor here.

In PowerPoint, Insert puts the picture on the slide in view: in its empty content box if it has one, else below its title, else in the middle. There are no captions. Update keeps the picture where you moved it and at the width you gave it, and puts its proportions back if it got stretched (drag a corner with Shift held to resize it evenly).

MD shows the whole document as Markdown, each diagram as its Mermaid, to copy into an LLM (or download as a .md file): most tools that read .docx files skip the Mermaid in the pictures' alt text.

Page to insert (for diagrams with several pages) picks the page that goes into the document: Lucid's editor doesn't tell the add-in which page you're looking at.

For LLMs, put arrow labels on the arrow (double-click it in Lucid and type), and drop arrow ends onto their boxes. A text box placed beside an arrow ends up as a loose note in the Mermaid: Lucid doesn't tell the add-in where things sit, so it can't know which arrow the text belongs to. Insert and Update say when a page has these.

If Lucid's editor asks you to log in, use the pane's Sign in to Lucid, not Lucid's own button: Lucid's opens your web browser, and logging in there doesn't reach the add-in.

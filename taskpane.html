There's one copy of each diagram, in your Lucid account. This editor and lucid.app are two windows onto that same diagram: edit in either, and every change saves to Lucid by itself.

Open in Lucid ↗ gives you more room and the Lucid features that don't work inside Word, like Create with AI. Changes made there appear here too.

The pictures in Word are snapshots. They only change when you click Update selected. The line above the buttons says whether the selected picture is up to date.

If the editor asks you to log in, log in to lucid.app in a browser tab (it can't be done inside Word), then click Switch diagram.

Page for Word (for diagrams with several pages) picks the page that goes into the document. It's separate from the page tabs in the editor because Lucid's editor doesn't tell the add-in which page you're looking at.

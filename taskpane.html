There's one copy of each diagram, in your Lucid account. This editor and lucid.app are two windows onto that same diagram: edit in either, and every change saves to Lucid by itself.

The pictures in Word are snapshots. Insert adds the diagram as a new picture below the cursor; Update brings the selected picture up to date. The line above the buttons says whether it is. Edit selected opens the selected picture's diagram here.

The menu at the top switches diagrams: the ones already in this document, your recent ones, or Browse or create in Lucid. ↗ opens the diagram on lucid.app for more room and the Lucid features that don't work inside Word, like Create with AI; ↻ reloads the editor here.

MD shows the whole document as Markdown, each diagram as its Mermaid, to copy into an LLM (or download as a .md file): most tools that read .docx files skip the Mermaid in the pictures' alt text.

Page for Word (for diagrams with several pages) picks the page that goes into the document: Lucid's editor doesn't tell the add-in which page you're looking at.

If the editor asks you to log in, log in to lucid.app in a browser tab (it can't be done inside Word), then pick the diagram again from the menu.
